# 1.- Instala docker
- https://www.docker.com/products/docker-desktop/

- Inicia docker

# 2.- Clona el proyecto
```
git clone https://github.com/raunogroch/mijael_project.git
```
# 3.- Ingresa a la carpeta mijael_project
```
cd mijael_project
```

# 4.- Levanta el proyecto
```
docker-compose up -d
```

# 5.- Abre el sistema 
```
http://localhost:81 #principal
http://localhost:8081 #base de datos
